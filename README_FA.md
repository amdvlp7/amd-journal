# راهنمای فارسی AMD Journal

## فایل‌های داخل بسته
- `index.html` — فایل اصلی وب‌سایت و رابط کاربری AMD Journal
- `supabase_setup.sql` — کد آماده ساخت جدول معاملات و تنظیم دسترسی امن کاربران در پایگاه داده Supabase
- `README_FA.md` — همین راهنمای فارسی

## وضعیت فعلی برنامه
نسخه اولیه وب‌اپلیکیشن آماده است؛ اما **ذخیره‌سازی ابری هنوز فعال نیست**. برای فعال شدن ورود با حساب کاربری و همگام‌سازی اطلاعات بین دستگاه‌ها، باید یک پروژه Supabase بسازی و اطلاعات اتصال آن را در فایل سایت وارد کنی.

تا قبل از اتصال Supabase، برنامه در حالت آزمایشی محلی اجرا می‌شود و اطلاعات فقط در همان مرورگر و همان دستگاه ذخیره می‌شوند. پاک شدن داده‌های مرورگر یا استفاده از دستگاه دیگر ممکن است باعث در دسترس نبودن اطلاعات شود؛ بنابراین این حالت را پشتیبان‌گیری ابری در نظر نگیر.

## مرحله اول: ساخت پایگاه داده ابری
1. به وب‌سایت [Supabase](https://supabase.com/) برو و یک حساب کاربری بساز.
2. یک پروژه جدید ایجاد کن.
3. پس از آماده شدن پروژه، از منوی سمت چپ وارد بخش **SQL Editor** شو.
4. فایل `supabase_setup.sql` را با یک ویرایشگر متن باز کن و تمام کد داخل آن را کپی کن.
5. کد را در SQL Editor قرار بده و گزینه **Run** را بزن.
6. این دستورها جدول معاملات را ایجاد می‌کنند و دسترسی هر کاربر را طوری محدود می‌کنند که فقط معاملات حساب خودش را ببیند و مدیریت کند.

## مرحله دوم: اتصال وب‌سایت به Supabase
1. در داشبورد Supabase وارد بخش **Project Settings** و سپس **API** یا بخش اطلاعات اتصال پروژه شو.
2. مقدار **Project URL** و کلید عمومی **publishable/anon** پروژه را پیدا کن.
3. فایل `index.html` را با یک ویرایشگر متن باز کن.
4. در انتهای فایل، عبارت `const CONFIG=` را پیدا کن. بخشی شبیه این می‌بینی:

   ```js
   const CONFIG={
     SUPABASE_URL:"YOUR_SUPABASE_URL",
     SUPABASE_ANON_KEY:"YOUR_SUPABASE_ANON_KEY"
   };
   ```

5. مقدار `YOUR_SUPABASE_URL` را با Project URL خودت جایگزین کن.
6. مقدار `YOUR_SUPABASE_ANON_KEY` را با کلید عمومی پروژه جایگزین کن.
7. فایل را ذخیره کن.

**هشدار امنیتی مهم:** هرگز کلید `service_role` یا کلید محرمانه سرور را داخل فایل وب‌سایت قرار نده. فقط از کلید عمومی مناسب سمت کاربر استفاده کن. سیاست‌های امنیتی تعریف‌شده در فایل SQL را هم حذف یا غیرفعال نکن.

## مرحله سوم: انتشار وب‌سایت
برای اینکه از کامپیوتر و موبایل به سایت دسترسی داشته باشی، باید پوشه پروژه را روی یک سرویس میزبانی وب منتشر کنی؛ برای نمونه می‌توانی از Netlify، Vercel یا GitHub Pages استفاده کنی.

به‌طور کلی:
1. در سرویس میزبانی موردنظرت حساب بساز.
2. پوشه پروژه یا فایل‌های داخل آن را طبق راهنمای همان سرویس بارگذاری کن.
3. پس از انتشار، نشانی HTTPS سایت را دریافت کن.
4. در تنظیمات Supabase، بخش **Authentication → URL Configuration**، نشانی سایت منتشرشده را به‌عنوان **Site URL** و نشانی مجاز بازگشت را تنظیم کن.

نام گزینه‌ها ممکن است با توجه به نسخه داشبورد سرویس کمی تفاوت داشته باشد.

## امکانات نسخه فعلی
- داشبورد تعداد معاملات بسته‌شده، نرخ برد، سود و زیان خالص و Profit Factor
- ثبت پوزیشن‌های Spot و Futures
- ثبت نام کوین، تاریخ و ساعت ورود، جهت معامله و دلیل ورود
- ثبت حال‌وهوای روز و احساس هنگام ورود
- ثبت قیمت ورود و خروج، حجم، کارمزد، حد ضرر و حد سود
- وضعیت پوزیشن باز یا بسته
- تاریخچه معاملات با امکان جست‌وجو، فیلتر، ویرایش و حذف
- محاسبه نرخ برد کلی هر کوین
- مقایسه نرخ برد Long و Short برای هر کوین
- تحلیل نتایج بر اساس احساس هنگام ورود
- ماشین‌حساب ساده حجم معامله بر اساس ریسک
- تغییر تم روشن و تاریک
- خروجی گرفتن از معاملات با فرمت CSV

## نکات محاسباتی و محدودیت‌ها
- برای پوزیشن Long، سود و زیان ناخالص برابر است با `(قیمت خروج − قیمت ورود) × حجم`.
- برای پوزیشن Short، سود و زیان ناخالص برابر است با `(قیمت ورود − قیمت خروج) × حجم`.
- سود و زیان خالص با کم کردن مقدار کارمزد کل از سود و زیان ناخالص محاسبه می‌شود.
- نرخ برد برابر است با تعداد معاملات سودده تقسیم بر تعداد تمام معاملات بسته‌شده. معاملات سربه‌سر نیز در تعداد کل معاملات بسته‌شده شمرده می‌شوند.
- فرمول سود و زیان فعلی برای قراردادهای خطی ساده طراحی شده است. قراردادهای معکوس، ضریب قرارداد، تسویه با ارز متفاوت، Funding و اسلیپیج ممکن است به فرمول اختصاصی نیاز داشته باشند.
- ماشین‌حساب ریسک، کارمزد، اسلیپیج، Funding، محدودیت مارجین، اهرم و حداقل اندازه سفارش صرافی را لحاظ نمی‌کند.
- این برنامه ابزار ثبت و تحلیل معاملات است و توصیه سرمایه‌گذاری یا تضمین سود محسوب نمی‌شود.

## پیشنهاد پیش از استفاده واقعی
ابتدا چند معامله آزمایشی با مقادیر ساختگی ثبت کن و خروجی سود و زیان و نرخ برد را با محاسبات دستی مقایسه کن. پس از اطمینان از صحت تنظیمات، از داده‌های واقعی استفاده کن و مرتب خروجی CSV پشتیبان بگیر.
